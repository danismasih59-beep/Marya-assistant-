MYRA_MANUAL

CORE ARCHITECTURE & APIS

v4.2.0

1. Zero-Trust Plugin Sandbox

Every plugin running within Myra AI Core operates as a sandboxed WebAssembly (WASM) guest inside an isolated hardware-enclave boundary. Outbound TCP connections are blocked by default unless granted explicit network.external scopes.

2. Titan Mesh Protocol

Distributed edge nodes share state using encrypted UDP gossip packets signed with ed25519 asymmetric keys. Synchronizations occur under 15ms latency across local wireless subnets.

3. Gemini Cognitive Routing

Natural language user directives are tokenized and streamed into Gemini 1.5 Pro to synthesize autonomous function calls and orchestration pipelines without human scripting.
